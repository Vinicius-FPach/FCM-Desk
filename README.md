# FCM-Desk

## 1 - Motivação do Projeto:
 - Visto que foi criada uma versão mobile previamente nomeada "FCM (FC Carrer Manager)", se notou a necessidade de uma versão desktop/WEB, principalmente por se tratar de uma aplicação que visa ser uma ferramenta para registro de dados de modos carreira como técnico nos jogos EA FC/FIFA, ou mesmo PES, aonde o usuário registra informações que são descartadas pelo jogo ao mudar a "temporada", como o artilheiro do time, os títulos conquistados e demais estátisticas relacionadas aos jogadores do time, bem como histórico de transferencias.
